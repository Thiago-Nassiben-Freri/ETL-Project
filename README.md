## ETL Project ⚙️

A simple Python algorithm that uses the ETL (Extract, Load, Transform) concept to filter the data generated by AI. After the ETL process, the data is used to create a Power BI dashboard.

## Structure 📋
```\src -> etl.py```  
```\data -> enem_dataset_com_erros.csv, enem_dataset_limpo.csv```    
```\dashboard -> dashboard.png```
